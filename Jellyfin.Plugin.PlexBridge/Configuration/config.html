Plex Bridge

Expose movie and TV libraries from a remote Plex Media Server as a Jellyfin Channel. Plex credentials remain on this Jellyfin server.

Use a URL for the shared Plex Media Server that this Jellyfin server can reach.
Stored in Jellyfin's plugin configuration and sent only from the server to Plex. It is never inserted into client playback URLs.
URL the Jellyfin server/FFmpeg can use to reach its own Plex Bridge proxy. Include your Jellyfin Base URL path if you use one.
Optional comma-separated Plex section keys. Leave empty to expose every movie and TV section shared with this Plex token.
Optional comma-separated Jellyfin user GUIDs. Leave empty to allow all Jellyfin users to browse this Channel.
Number of Plex records fetched per upstream request. Jellyfin 10.11 requests complete Channel folders, so Plex Bridge automatically walks all batches.
Default 1440 (24 hours). A signed URL authorizes only one Plex item/version and contains no Plex token.
